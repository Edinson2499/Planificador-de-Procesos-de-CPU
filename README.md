# Planificador-de-Procesos-de-CPU
(manejo de colas, transiciones de estado como Nuevo, Listo, Ejecución, Bloqueado, Terminado y cálculo de tiempos de duración/ráfaga, espera y retorno), la clave está en separar la lógica de simulación de la interfaz de usuario para que puedas agregar fácilmente distintos algoritmos (FIFO/FCFS, SJF, Round Robin, Prioridades).
